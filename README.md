# 💹 USD to PKR Forex Prediction Dashboard

This is a **Computational Finance** project that analyzes historical USD to PKR rates and predicts future trends using Machine Learning.

## 🚀 Features
- **Live Dashboard:** Interactive charts using Streamlit and Plotly.
- **Market Analysis:** 20-day Moving Averages and Volatility tracking.
- **ML Prediction:** Uses **Random Forest Regressor** for accurate future price forecasting.
- **Data Source:** Historical Forex data (2010 - 2024).

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Streamlit, Pandas, Scikit-Learn, Plotly
- **Deployment:** Streamlit Cloud

## 📈 How to use
1. Select the date range from the sidebar.
2. Use the slider to choose how many days you want to predict.
3. View the 'Future Forecasting' tab for ML results.
